# 대화 감지 제품 연결 초안 — 시연 브랜치에 포함하지 않음

실행 가능한 전체 데모는 feat/ui-demo-handoff-1112와 docs/setup/DEMO_OTHER_LAPTOP.md를 사용한다. 이 초안은 전체 데모 요청으로 중단된 제품 연결 작업을 보존하기 위한 Draft PR이다.

VoiceCheckPort의 졸음 확인 요청 전에 CabinSpeechSampler를 통해 CabinMonitor의 10초 감지를 시작하고, 결과를 OccupancyContext.speechDetected에 전달한다. 마이크 동의·권한이 없으면 기존 버튼 대체를 유지한다. 감지 실패도 조용함으로 확정하지 않고 마이크 불가 경로를 사용한다. 취소된 요청의 늦은 감지 콜백은 무시한다. 서비스와 제품 데모에 샘플러를 주입하고 종료 시 정리한다.

사용자 확정: 질문 대상은 기존대로 항상 운전자. CheckPolicy의 대상 선택 규칙은 변경하지 않았다. 10초 준비 시작을 실행 STARTED로 전달해 제품 데모는 검사 동안 1배가 된다. 실제 응답 시간은 감지 종료 뒤 신호음부터 기존 경로로 측정한다.

남은 검증:
- 실제 제품 세션의 10초 감지 → 운전자 질문·직접 발화 전체 기기시험
- 감지 중 취소·권한 철회·설정 변경·세션 종료의 회귀시험
- CabinMonitor의 취소 직후 새 검사를 시작할 때 이전 worker가 새 recorder를 정리하지 않는지 수명 검토
- 화면 밖 마이크 수집 허용 범위와 현재 서비스 유형의 검토

부품 화면에서 확인한 조용함 false·발화 true는 이 제품 연결 초안 통과를 뜻하지 않는다. 이 PR을 실행용 PR과 함께 자동 병합하지 않는다. 원본 음성은 저장하지 않는다.
