# 2026-11-12 distraction 수정·PR #21 기대값 검증

## 수정

- 기존 검증용 `data/scenarios-demo/distraction.json`의 955.0~959.9초를 0°로 고정하고 960.0·960.1초에 8°를 넣었다. 실제 변경은 조향 50개 샘플이며 다른 신호·메타데이터는 보존했다. 실제 엔진이 이 급조향을 검출하는 회귀 시험을 추가했다.
- 제품용 `data/scenarios/distraction.json`에는 기존부터 25초 고정 후 급조향이 있어 보존했다. 제품용 고정 구간을 5초로 줄이면 이상 분의 미세 수정 감소 조건이 부족해지므로 두 데이터 경로를 혼동하지 않는다.
- JVM·기기시험에서 distraction의 최고 단계를 ‘2 이하’에서 ‘정확히 2’로 강화했다. 끝까지 0단계여도 통과하던 허점을 막고 튐형 분류도 확인한다. 실제 딴짓 건수 저장(PAT_004)과 SPIKE 분류는 구분한다.
- 기기시험의 drowsy에는 과거 점수·단계 시각을 고정한 기대값이 없었다. 최고 점수·첫 3단계 시각·응답 가정을 결과 파일에 추가했다.

## PR #21 비교

`origin/pr-21`의 bb0fbc2를 가져와 `/tmp/sleepissue-pr21-validation`에서 현재 HEAD와 임시 통합했다. 현재 작업 브랜치에는 병합·커밋·push하지 않았다. 같은 수정 데이터와 시험으로 비교했다.

| 검증 경로 | 현재 엔진 | #21 적용본 |
| --- | --- | --- |
| JVM 급조향 | 2회(20:00·25:00) | 5회(17:30·20:00·22:30·25:00·27:30) |
| JVM 최고 평활 위험도 | 83.40297 | 98.81442 |
| JVM 3단계(사람 응답 없음) | 25:10 | 22:10 |
| 제품 기기 drowsy 최고 위험도 | 93.022865 | 98.60164 |
| 제품 기기 drowsy 3단계 | 23:40 | 22:10 |

JVM은 원본 전수의 결정적 경로, 기기시험은 실제 경과·Hub 발행·관측을 거치는 경로다. 기기 보고서의 최고값은 관측된 값이며 원본 전수의 최고값과 같다고 단정하지 않는다. 기기에 정확한 98.8점·18:55를 고정하지 않는다.

요청의 18:55는 느린 응답 두 번을 가정한 결과다. 이번 기본 제품 기기시험은 음성·SDK 실행과 사람 응답이 없으므로 같은 시각을 기대하지 않는다. `AWAKEDRIVE_EXPECT_PR21=true`를 켠 JVM 회귀에서는 급조향 정확히 5회와 최고 98.8±0.1점을 검증했다.
