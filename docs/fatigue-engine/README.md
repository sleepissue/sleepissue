## 한 줄 요약

10 Hz 주행 신호에서 **운전대 조향 모양만 보고** 30초마다 졸음 의심 점수(0~100)를 낸다. 짧게 튀는 딴짓과 계속 나빠지는 졸음을 나누고, 크루즈(보조 주행) 중에는 조향을 판단에서 뺀다.
단계(0~3)를 정하거나 음성으로 묻는 일은 하지 않는다. 그건 1번(단계 전환)·3번(음성)이 이 엔진의 출력을 받아서 한다.

## 용어

| 용어 | 뜻 |
| --- | --- |
| 게이트 | 조향을 졸음 판단에 써도 되는 순간만 통과시키는 필터. 고속·D단·직진 구간만 남긴다 |
| 미세 수정 | 방향이 바뀌는 0.5~3° 조향. 깨어 있으면 많고 졸리면 줄어든다 |
| 큰 수정 | 방향이 바뀌는 5° 이상 조향. 졸리면 늘어난다 (차선 쪽으로 흘렀다가 크게 되돌림) |
| 멈춤 뒤 급조향 | 4초 넘게 운전대가 거의 안 움직이다(0.5° 미만) 1초 안에 6° 이상 꺾음. 졸다 깨거나 딴짓하다 놀랐을 때 |
| f값 | 지표를 기준과 비교해 0~1로 바꾼 값. f미세·f큰·f급조향 |
| B | 행동 점수 0~100 = 100 × (0.35·f미세 + 0.25·f큰 + 0.40·f급조향) |
| K | 맥락 가중 1.00~1.35. 오래 운전·새벽·혼자·더움·하루 누적이 길면 커진다 |
| R | 위험 점수 = min(100, B × K). 순간값 |
| 평활값 | R의 3분 지수평균. 단계 판단(1번)은 이 값을 쓴다 |
| 기본값 / 평소의 나 / 오늘의 나 | 비교 기준 세 가지. 기본값은 [가정] 미세 20/분·큰 4/분, 평소의 나는 지난 운행 중앙값, 오늘의 나는 이번 운행 처음 15분 |
| 출발 피로 | 처음 15분이 평소보다 나쁨 → 민감 모드 |
| 민감 모드 | 출발 피로 또는 '졸려요'. 1번이 단계 문턱을 30/50/70으로 낮춘다 |
| 이상 분 | 미세 수정이 줄고 큰 수정·급조향이 있던 1분 |
| 추세형 / 튐형 / 애매 | 최근 10분 이상 분 6개 이상 / 3개 이하이면서 매번 1분 안 회복 / 그 사이 |
| 안전 우회 | 5분 안 급조향 3회. 원인을 따지지 않고 3단계로 보내는 신호 |
| 보조 주행 | 크루즈 작동 중(또는 조향 값을 못 받음). 조향을 판단에서 뺀다 |
| 인계 품질 | 크루즈를 끈 직후 30초 안의 조향이 거친지 |
| 조작 공백 | 마지막 조작(방향지시등·브레이크·크루즈·통풍) 뒤 지난 초 |
| `[해석]` / `[제안값]` / `[가정]` | 기획서 해석으로 정한 것 / SRS에서 새로 정한 값 / 근거 없이 임시로 둔 값 |
