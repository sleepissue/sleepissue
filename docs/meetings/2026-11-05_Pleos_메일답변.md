# Pleos(공모전 운영사무국) 메일 답변 정리 — 2026-11-05

> 정리: 2번. 운영사무국에 보낸 문의와 받은 답을 팀이 같이 보려고 남긴다.
> 보낸 메일은 11/2 최종안("허가 여부 먼저" 판)이다. 19문항 초안은 보내지 않은 이전 안이다.

## 1. 보낸 질문 (요약)

- **가. 비공개 데이터 사용 허가·제공 가능 여부**: LFA·LKA 상태와 운전자 조향 토크, 차로 이탈 경고·LKA 개입, 핸즈온·핸즈오프 경고, DAW 주의 수준·휴식 권장·주의 분산 경고, 시트·핸들 진동 → ① 가능/불가/검토 중 ② 받는 방법(권한·절차·시기) ③ READ_ADAS_STATES·Safety Telltale API
- **나. 쓰고 있는 API 확인**: 조향각 분해능·갱신 주기, LFA·LKA 시스템 조향이 값에 반영되는지 / 화면 없는 포그라운드 서비스로 백그라운드 구독 가능 여부, 종료 정책, 권장 유형

## 2. 받은 답

**1차 답**

1. ADAS SDK는 사용할 수 없다. 다만 LFA·LKA 등 개별 신호를 다른 모든 경로로도 받을 수 없다는 뜻은 아니다.
2. 속도·조향각은 기본 1 Hz(1초 간격)로 구독해 받은 값을 콜백으로 준다. 같은 값이 유지되면 직전 전달 뒤 3초 안의 중복 콜백은 생략한다. 실제 간격은 차량 지원 주기·값 변화에 따라 다르다.
3. 화면을 쓰지 않는 포그라운드 서비스가 주행 중 차량 신호를 받는 것은 가능하다. 부팅·시동 자동 시작, 앱 프로세스 종료 뒤 실행, 개별 API·권한 전체 지원은 보장하지 않는다.

**2차 답**

- 공모전 자료는 Pleos Playground 문서가 전부다. 별도 신청·승인·자료 전달 절차는 없다. Connect SDK·NaviHelper는 공개 문서의 API 외에는 제공하지 않는다.
- 남은 세부 질문은 공식 확인 뒤 추가 안내 예정.

## 4. 아직 답 없는 것

- 조향 값이 전륜각인지 운전대각인지, 부호, 분해능 (1번 11/3 확인: 공개 SDK 설명은 front-wheel angle, Virtual Console +10 → SDK −10 → 지금은 엔진에 null로 보류)
- LFA·LKA 작동 중 시스템 조향이 조향 값에 반영되는지
