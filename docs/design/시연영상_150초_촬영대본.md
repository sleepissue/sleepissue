## 녹화·편집 원칙

- OBS로 에뮬레이터 화면과 시스템 오디오를 함께 녹화한다. `adb shell screenrecord` 영상에는 앱 소리가 들어가지 않는다.
- 데모 장면의 ‘데모 재생 중’ 표시를 유지한다. 배속 구간은 ‘시연을 위해 시간 가속’ 자막을 넣는다.
- 실제 SDK 성공과 데모 판단 결과를 구분한다. 미연결 기능을 편집으로 성공한 것처럼 만들지 않는다.
- 6종을 모두 검증하되 최종 영상에는 핵심 흐름을 충분히 읽을 수 있도록 배치한다.
- 개인정보·CRN·개발자 콘솔·로컬 경로가 화면에 나오지 않게 제품 화면만 캡처한다.
